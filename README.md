# PIO Application Checker

Расширение для Chrome. Следит за заявлением на карту побыту в портале
**Przybysz** Нижнесилезского воеводского управления
([pio-przybysz.duw.pl](https://pio-przybysz.duw.pl/)): показывает этап
рассмотрения, инспектора, сколько дней дело в работе и все сообщения ведомства.
Проверяет портал само, по таймеру.

Страница с роликом и инструкцией: <https://markarov.dev/demo/piopa/>

> Независимый проект. Не связан с Dolnośląski Urząd Wojewódzki и порталом
> Przybysz. API портала не опубликован: расширение повторяет запросы, которые
> делает сам сайт, и может перестать работать, если портал их изменит.

*English: a Chrome extension that follows a residence-permit application in the
Przybysz portal of the Lower Silesian Voivodeship Office (Wrocław) — stage,
inspector, days in progress and the office's messages. Interface in English,
Russian and Polish. Independent, not affiliated with the office.*

## Установка

**Из магазина:** [Chrome Web Store](https://chromewebstore.google.com/detail/pio-application-checker/fnjpidolmicogfgpjeekmhbfknajbkgc).
Пока новая версия не прошла проверку магазина, там лежит 6.0 (июнь 2025).

**Вручную, свежую версию из этого репозитория:**

1. Скачайте архив со страницы <https://markarov.dev/demo/piopa/> и распакуйте,
   либо клонируйте этот репозиторий.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. «Загрузить распакованное расширение» → папка с `manifest.json`.

Дальше в обоих случаях: значок расширения → «Открыть настройки», почта и пароль
от портала, кнопкой «Получить заявления» добавить свои номера, сохранить.

## Что видно

- **Окно расширения.** По каждому заявлению: этап (как его называет портал,
  по-польски), инспектор, счётчик дней от принятия заявления. Ниже сообщения,
  свежие сверху. Сообщение о решении (`Decyzja…`) выделено зелёным, и счётчик
  останавливается на его дате.
- **Значок.** Число — сколько сообщений пришло за выбранный период. Синий — вы
  всё видели, оранжевый — есть сообщение новее последнего открытия окна,
  красный `!` — последняя проверка не удалась (причина написана в окне).
- **Настройки.** Период показа (от 5 часов до всего времени) и частота проверки
  (от 30 минут до 10 часов, по умолчанию 3 часа).

## Данные

- Почта, пароль и номера заявлений лежат в `chrome.storage.local` — только в
  этом браузере. До версии 6.0 включительно они (и последний токен доступа)
  хранились в `storage.sync` и попадали в синхронизацию аккаунта Google; 6.1
  при первом запуске переносит настройки и удаляет синхронизированную копию
  вместе с токеном. На втором компьютере со старой версией настройки после
  этого придётся ввести заново.
- Запросы уходят на один адрес: `https://api-przybysz.duw.pl` (это и есть
  единственное разрешение в `manifest.json`). Аналитики и сторонних серверов нет.
- Хранится только то, что показывается: заголовок и дата сообщения, этап,
  инспектор, дата принятия заявления.

## Устройство

| Файл | Что в нём |
|---|---|
| `core.js` | Всё общение с порталом, настройки, логика значка, тексты. Подключается и служебным процессом, и страницами |
| `background.js` | Служебный процесс: таймер и проверка |
| `popup.html` / `popup.js` | Окно: показывает сохранённый результат и просит служебный процесс обновить его. Само в портал не входит |
| `options.html` / `options.js` | Настройки |
| `_locales/{en,ru,pl}` | Тексты интерфейса. Язык берётся из языка браузера |
| `test/` | `node --test test/` — без сети, на выдуманном аккаунте |
| `tools/` | Стенд для разработки, снимков и ролика. В расширение не входит |

Этапы (`Wniosek złożony`, `Decyzja wydana`, …) в `core.js` не переведены
намеренно: это слова, которыми ведомство пишет в письмах.

## Разработка

```bash
node --test test/                 # 16 тестов, сеть не нужна
node tools/harness.mjs            # http://127.0.0.1:8787/popup.html?lang=ru
```

Стенд открывает `popup.html` и `options.html` как обычные страницы: `chrome.*`
подменён (`tools/shim.js`), портал — выдуманный аккаунт из `tools/mock-data.js`.
Параметры: `?lang=ru|en|pl`, `?state=empty`, `?wrong=1`, `?delay=600`.

```bash
cd tools/video && npm install
node realcheck.mjs                # расширение в настоящем Chrome: манифест, языки, служебный процесс
node shots.mjs                    # store/shot-ru-1..3.png
DRY=1 node build.mjs              # прогон сцен ролика без голоса
node build.mjs                    # ролик с озвучкой (нужен ELEVENLABS_API_KEY)
```

**Чего стенд не проверяет:** настоящих ответов портала. Форма запросов в
`core.js` та же, что в 6.0 (это закреплено тестом), но после любой правки
`fetchAll` расширение надо открыть со своей учётной записью.

Выпуск в магазин: поднять `version` в `manifest.json`, собрать архив, загрузить
в [кабинет разработчика](https://chrome.google.com/webstore/devconsole).

Архив для страницы: `zip -r piopa-<версия>.zip manifest.json *.js *.html ui.css icons _locales`.
